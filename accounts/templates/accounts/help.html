MEETCLONE SUPPORT

Help Center

Find answers to common questions and learn how to use MeetClone.

1. Getting Started

Create or log in to your MeetClone account to start using meetings and account features.

  • Create an account or log in.
  • Complete your profile if needed.
  • Use the Home page to create or join a meeting.

2. How to Create a Meeting

To create a new meeting:

  1. Open the Home page.
  2. Click New Meeting .
  3. Enter the meeting title and other available information.
  4. Create the meeting.
  5. Share the generated meeting code with the people you want to invite.

3. How to Join a Meeting

If someone shares a MeetClone meeting code with you:

  1. Open the MeetClone Home page.
  2. Enter the meeting code in the Enter a meeting code field.
  3. Click Join .
  4. Continue to the meeting room when the meeting is available.

4. Meeting Code

A meeting code is generated when a meeting is created. The host can share this code with participants.

You can copy the meeting code from the meeting details page and share it through supported communication methods.

5. Profile

Click your profile area in the Home page navigation bar to open your profile.

Depending on the available account settings, you can manage your profile information, profile picture, bio, privacy settings, notifications, and account security.

6. Password and Account Recovery

If you forget your password, use the account recovery or password reset options available on the login page.

Follow the verification steps provided by MeetClone to recover access to your account.

7. Notifications

MeetClone provides notification settings that allow you to manage available account and meeting-related notifications.

Open your account notification settings to review or update your available notification preferences.

10. Common Problems

Meeting code is not working

Check that the code was entered exactly as provided by the meeting host.

Meeting has ended

An ended meeting may no longer be available to join.

Profile picture is not visible

Check your profile and make sure a profile picture has been uploaded.
